# Gestor Financeiro Pessoal (PWA) 💰

## 📖 Sobre o Projeto

Solução de Computação Móvel desenvolvida como um **Progressive Web App (PWA)**
para gestão de finanças pessoais. O objetivo é demonstrar a aplicação de
conceitos de computação ubíqua, permitindo o controle de ingressos e egressos em
qualquer dispositivo.

## 🚀 Tecnologias Utilizadas (Stack)

- **Frontend:** FlutterFlow (Interface e Lógica de Cliente).
- **Backend/Database:** Supabase (Autenticação e Banco de Dados PostgreSQL)
- **Metodologia:** Kanban (Gerido via Notion)

## 🗂️ Modelo de Dados

O sistema utiliza uma tabela `transactions` vinculada ao `auth.users` do
Supabase para garantir a segurança e isolamento dos dados por usuário.

## 🛠️ Como Executar

Este projeto está hospedado na web.

Acesse:

<https://app-financas-byte-seguro.flutterflow.app/>

## **Instruções de Instalação (PWA):**

> 1. Acesse o link via navegador (Chrome no Android / Safari no iOS).
> 2. No Android: Toque em "Opções" > "Adicionar à Tela Inicial".
> 3. No iOS: Toque em "Compartilhar" > "Adicionar à Tela de Início".
